A **set** is a collection of unordered objects. These objects are referred to as **elements** or **members** of the set [1, p. 21].

The simplest way to write a set is to list all of its values:
$$
	A=\{ 1,2,3,4 \}
$$
states that the set $A$ contains the elements $1$, $2$, $3$, and $4$ [1, p. 22].

The order and duplicates of a set do not matter. Hence,
$$
	A=\{ 4,2,3,3,1,2 \}
$$
is an equivalent definition of $A$ [1, p. 22].
